\section{Approach: Gatekeeper}
\label{sec:approach}
Figure~\ref{fig:pipeline} summarises the pipeline.  For a skill $S$ and a target context, Gatekeeper proceeds as follows.

\begin{figure}[t]
\centering
\begin{tikzpicture}[font=\scriptsize, node distance=6mm and 4mm,
  box/.style={draw, rounded corners=2pt, align=center, minimum height=8mm, text width=17mm, inner sep=2pt},
  arr/.style={-{Stealth[length=1.6mm]}}]
\node[box] (pkg) {skill package\\$\langle\pi,\mathcal{D},\mathcal{I},\mathcal{P},\mathcal{K}\rangle$};
\node[box, right=of pkg] (scr) {scope screen\\$\mathcal{I}(x)$, $\mathcal{D}$};
\node[box, right=of scr] (bind) {AST binder\\(abstains)};
\node[box, right=of bind] (tri) {paired trials\\with / without $\pi$};
\node[box, right=of tri] (cert) {e-process\\$\ge 1/\alpha_{c,k}$?};
\node[box, right=of cert] (quar) {quarantine};
\node[box, below=of cert] (adm) {admit cell $c$};
\node[box, below=of tri] (exe) {execution rule:\\components admitted?};
\node[box, below=of bind] (comp) {composite cells\\(overlapping $\mathcal{K}$)};
\node[box, below=of pkg] (ret) {retirement:\\next ledger epoch};
\draw[arr] (pkg) -- (scr); \draw[arr] (scr) -- (bind); \draw[arr] (bind) -- (tri); \draw[arr] (tri) -- (cert);
\draw[arr] (cert) -- node[above]{no} (quar);
\draw[arr] (cert) -- node[right]{yes} (adm);
\draw[arr] (adm) -- (exe);
\draw[arr] (exe) -- node[above]{no} (comp);
\draw[arr] (comp.north east) -- (tri.south west);
\draw[arr] (ret) -- (pkg);
\end{tikzpicture}
\caption{Gatekeeper.  ``No'' at the e-process means the trial budget was spent.  Evidence comes from paired trials on the target scope; each cell (single skill or composite) has its own
entry in a pre-allocated error ledger; overlapping skills run together only when their composite cell is admitted; a fingerprint change
retires an admission and re-admission draws the next ledger entry.}
\label{fig:pipeline}
\end{figure}
\begin{enumerate}
\item \textbf{Scope screen.}  Evaluate the input assumptions $\mathcal{I}$ and compare the fingerprints $\mathcal{D}$; missing
information means \textsc{OutOfScope}.  A pass is necessary, not sufficient: the motivating example passes it.
\item \textbf{Bind.}  Apply $\pi$ with an AST binder that abstains on ambiguity (no match, several matches, an existing guard, a
shadowed built-in, a missing symbol) instead of guessing.
\item \textbf{Paired trials.}  Draw tasks of the target scope with replacement; run each with and without the skill on the same
snapshot and seed, in a fresh worker process; record $Z=\ell(x,\pi)-\ell(x,\varnothing)$.
\item \textbf{Certify.}  Update the betting e-process of the cell (Lemma~\ref{lem:eprocess}); admit when it reaches $1/\alpha_{c,k}$,
the cell's entry in the pre-allocated ledger; quarantine when the budget is spent.  A harm alarm (an e-process for a high harm rate)
rejects early when harm is frequent.
\item \textbf{Compositions.}  When an admitted skill's footprint overlaps another's, the composite is enqueued as its own cell; until
it is admitted, the execution rule keeps the two from running together.
\item \textbf{Retirement.}  When the fingerprint of an admitted scope changes, admission is revoked; re-admission draws the next entry
of the cell's ledger ($6/(\pi^2(k+1)^2)$ of its share at epoch $k$), so revocations cannot inflate the error budget.
\end{enumerate}
Capability approval is consumed as a precondition and never merged into the functional decision; the two verdicts and their
evidence are stored separately.
